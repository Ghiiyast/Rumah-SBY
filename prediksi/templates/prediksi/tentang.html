PENGENALAN APLIKASI

Mengenal Rumah SBY

Memahami nilai rumah, melalui data dan teknologi.

Rumah SBY merupakan aplikasi berbasis web yang membantu pengguna memperkirakan harga rumah di Surabaya menggunakan teknologi Machine Learning. Aplikasi ini memanfaatkan karakteristik properti untuk menghasilkan estimasi harga berdasarkan pola dari dataset yang digunakan.

ALUR KERJA

Bagaimana Rumah SBY Bekerja?

01

Data Properti

Kumpulan data karakteristik dan harga rumah di Surabaya.

02

Persiapan Data

Pembersihan data dan penyesuaian kolom kategori agar dapat diproses oleh model.

Pelatihan Model
